# Acuerdo de trabajo en GitHub — AdoptaPet

## Organización de ramas

- La rama `main` será utilizada para conservar las versiones integradas y revisadas del proyecto.
- Cada integrante trabajará en una rama relacionada con su tarea o funcionalidad.
- Los cambios se realizarán primero en la rama correspondiente de cada integrante.
- Los cambios terminados podrán integrarse a la rama `main` después de ser revisados.

## Commits

- Cada integrante deberá realizar commits que describan claramente el cambio realizado.
- Se evitarán mensajes de commit poco descriptivos como "cambio" o "prueba".

## Integración

- Antes de integrar cambios a la rama `main`, se verificará que no existan conflictos con el trabajo de los demás integrantes.
- Cada integrante será responsable de mantener actualizada su rama.
- Los cambios deberán revisarse antes de integrarse a `main`.

## Trabajo colaborativo

- Cada integrante trabajará en las tareas que le fueron asignadas.
- Los aportes realizados deberán quedar registrados en GitHub.
- Todos los integrantes deberán realizar aportes verificables en el repositorio.
- El equipo mantendrá el repositorio organizado y actualizado.

## Proyecto

**AdoptaPet — Sistema web de gestión de adopción de mascotas.**
